One dad joke, told at the dinner table: a dad warns his kids the calendar's days are numbered, and his son answers with the literal truth. The pun is "days are numbered" — doomed vs. literally numbered — and the punchline lands at the end.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR`).
